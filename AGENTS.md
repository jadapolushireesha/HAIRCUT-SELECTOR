# Haircut Selector Development Rules

- Use TypeScript.
- Keep components modular.
- Never delete working features without approval.
- Never replace the provided hairstyle images.
- Never use random online hairstyle images.
- Use exactly the provided hairstyle assets.
- Keep hairstyle data centralized.
- Keep AI services separate from UI components.
- Never hard-code API keys.
- Use environment variables for secrets.
- Test every feature after implementing it.
- Fix errors instead of only reporting them.
- Keep the application responsive.
- Treat hairstyle suitability as an AI recommendation, not an objective beauty judgment.
- Do not make insulting comments about users.
- Preserve existing functionality when adding new features.
